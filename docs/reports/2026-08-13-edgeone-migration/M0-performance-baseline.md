- 当前全网平均响应约 1.916 秒，移动平均约 2.084 秒，西北与西南平均超过 2 秒。
- 该数据支持“现网存在国内访问优化空间”，但不证明 EdgeOne 在无 ICP 的境外区域能改善大陆体验。
- M5 必须使用相同探测工具、相同 URL、同一时间窗复测，并补充成功率、TLS、DNS、TTFB、LCP 与城市级原始记录。
