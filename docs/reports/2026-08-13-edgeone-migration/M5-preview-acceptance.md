# M5 任务卡：EdgeOne Preview 全量验收

**编号**: MIG-EO-M5
**前置**: M2–M4 全部签字
**状态**: ⏸️ 待开工确认
**预计**: 2–3 天 + 24 小时稳定性观察
**生产权限**: 无

## 1. 任务目标

在与 Vercel 相同 release commit、相同 Preview 数据条件下，证明 EdgeOne 方案达到功能、性能、稳定性、安全和回滚要求。

## 2. 功能验收

- [ ] 访问码、登录、退出、密码重置。
- [ ] 教师建课、材料上传、PDF 解析、大纲与内容生成。
- [ ] 图片、视频、TTS、重新配音和课堂生成任务。
- [ ] 保存、发布、分享、学习、答题和学习事件上报。
- [ ] 管理员学生/教师管理、学习任务、报表和数据问答。
- [ ] 移动端关键路径和主流浏览器回归。
- [ ] 全部 82 个 Route Handlers 至少完成契约级验证。

## 3. 非功能验收

- [ ] 国内三地三网与至少一个海外节点的页面/API 性能对比。
- [ ] 20 并发核心 API、5 并发重任务的容量探针。
- [ ] EdgeOne、Worker、Supabase 日志关联验证。
- [ ] Worker 终止、上游超时、Storage 失败、Supabase 短暂不可用故障注入。
- [ ] Secret 泄露、未授权 Worker 调用、上传类型/大小绕过检查。
- [ ] Preview 连续 24 小时无 P0/P1，错误率达到总规划指标。

## 4. 回滚演练

1. 将 Preview 入口从 EdgeOne 切回 Vercel。
2. 关闭新任务 feature flag。
3. 验证已提交任务不会丢失或被双重执行。
4. 验证浏览器缓存、Cookie、Supabase session 不阻断回退。
5. 记录实际 RTO，必须 ≤ 15 分钟。

## 5. 交付物

- `M5-preview-acceptance-report.md`：逐项证据、截图/日志索引和遗留风险。
- 性能对比表、故障注入报告、安全检查结果。
- 生产环境变量差异清单。
- M6 切流 Runbook 草案与 Go/No-Go 建议。

## 6. Go / No-Go 门禁

以下任一情况必须 No-Go：

- 核心用户旅程存在 P0/P1；
- 大陆访问没有可证明改善，或 ICP/区域与测试环境不一致；
- 仍有任务依赖本地文件、`after()` 或超过 120 秒同步执行；
- 回滚演练超过 15 分钟；
- EdgeOne 商业化或额度风险没有负责人接受。

## 7. 边界

- ❌ 不改生产 DNS，不执行 Production SQL，不写生产 Secret。
- 验收通过只代表可申请 M6，不自动授权生产切流。
