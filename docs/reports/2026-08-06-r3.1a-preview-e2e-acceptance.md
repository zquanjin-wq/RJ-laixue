## 3. 新发现问题（另立案，不阻塞本线）

**F-1 chat 影子写 IDEMPOTENCY_CONFLICT**：课堂 chat（AI 教师讲解消息）产生 6+ 次 `POST …/records 409 IDEMPOTENCY_CONFLICT`，record id 形如 `session-<ts>-<rand>:lecture-msg-<ts>`「同 id 不同内容」。
- 影响面：chat shadow 直写路径（R2 链路，非 outbox），与 R3.1a playback 改动无关（本次改动未触碰 chat）
- 疑似：讲解消息重复落库时 id 复用但内容被更新（重渲染/双语/追加写），或 React StrictMode 双写
- 处置：另立调查卡，归入排队项②（client-diagnostics 400 调查）或独立卡；建议在 chat shadow 也迁 outbox 时一并解决
