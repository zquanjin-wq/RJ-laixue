### 关键架构决策
1. **三开关门禁**: `NEXT_PUBLIC_RUNTIME_SHADOW` ∧ `NEXT_PUBLIC_RUNTIME_SHADOW_QUIZ` ∧ `localStorage.r3:quiz:outbox:ready`
2. **链尾专表隔离**: `runtimeChainHeads` 独立表，不复用 `succeededEntries`（保留 R3.0 契约）
3. **Strict chain**: 严格 5 段，每段依赖前一相位的链尾；completed vs archived 不同 semanticKey
4. **Dexie 同事务**: 入队与链尾更新在同一 rw 事务，刷新恢复仅靠 Dexie
5. **递归调度器**: 沿 dependsOnEntryId 任意深度解析（pending/sending/succeeded/dead/superseded）

### 单元门禁未覆盖项
下列项必须在 Preview E2E 验证：
- 真实 HTTP 链路 (curl → POST /api/runtime/v1/sessions)
- 真实 IndexedDB 状态 (跨刷新、跨标签页)
- 真实服务端响应 (成功/409/404/5xx)
- 真实 telemetry 上报
- 真实 chat/playback 无回归
