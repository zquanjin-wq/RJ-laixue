## 1. 更正与完成定义

上游 OpenMAIC 1.0 已经能通过 `/pptx-import` Skill 将 PPTX 导入并继续完成页面检查、课程角色、讲稿、动作及语音等课堂化处理。入口较深不代表能力不存在。本项目此前将“PPTX 可解析并保存为可编辑课件”当作 PPT 功能阶段完成，验收口径不完整。

从本版起，以下结果同时成立才可称为“通过 PPT 创建 AI 课程完成”：

1. 原 PPT 每页进入正式课程，顺序、可编辑内容、讲者备注和来源关系可追溯。
2. 课程拥有且仅拥有一个有效 AI 教师，并按策略生成伴学/学员角色；角色含 persona、头像、颜色及可用声音配置。
3. 每个可讲授页面有与页面内容一致的讲稿，讲者备注优先，AI 补充可识别。
4. 每页生成有效的 speech/spotlight/laser 等动作；动作不得引用不存在的元素。
5. 开启配音时，每段必需讲稿具有可播放音频；失败页明确标记并可单页重试。
6. 用户能看到持续更新的思考/执行过程、工具结果、警告和页级进度，不出现无输出干等。
7. 生成结果原子写入正式课程，可重开、编辑、试听、播放、发布；中断后可恢复且不重复建课。
8. 使用指定真实 PPTX 在生产环境完成端到端冒烟；只验证上传或只看到幻灯片不算通过。

### 上游实现边界（本轮必须遵守）

上游不是只提供一个 PPTX 解析器。`upstream/main` 已有以下成套实现：

| 上游模块 | 上游职责 | 本地处理方式 |
|---|---|---|
| `skills/agent-runtime/pptx-import/SKILL.md` | 规定建课、导入、角色、检查修复、动作与 TTS 的顺序和限制 | 作为本产品一键流程的行为契约，原文同步并做中文产品提示适配，不另写一份相互矛盾的流程 |
| `lib/server/agent-runtime/import-pptx.ts` | `import_pptx`、PPTX 限制、超时、幂等导入、讲者备注初稿 | 复用已有 importer；将其结果落入本地 PostgreSQL 课程模型，补齐来源资产/COS 关系 |
| `lib/server/agent-runtime/roster-tools.ts` | `set_roster`、`list_voices`、恰好一名教师及声音绑定校验 | 复用字段契约与校验语义，适配本地 `stage.generatedAgentConfigs` 与声音解析器 |
| 上游 `generate_actions` / `generate_tts` 工具链 | 逐页生成带元素引用校验的动作与音频 | 优先接入本地已有的同源动作/TTS 服务；不得用固定模板代替生成工具 |

本地分支与上游没有共同 Git 基线，且没有 `lib/server/agent-runtime/` 与
`skills/agent-runtime/` 这套文件。因此不能机械 cherry-pick；但这不是重新发明
行为的理由。每一个适配项必须指向上表中的上游契约、工具或测试。

## 3. 目标执行链

`描述教学需求 → 确认 PPT 来源 → 导入页面 → 检查/预览 → 轻量修复 → 生成 roster → 逐页生成讲稿 → 逐页生成动作 → 逐段配音 → 全课校验 → 原子提交 → 进入编辑器并自动保存`

任务数据库记录结构化状态；UI 同时展示可读的思考摘要和工具执行记录。自然语言过程用于透明体验，结构化步骤、产物指纹和状态才是恢复与提交依据。

教学需求是 PPTX 任务的必填输入，不是上传后可有可无的补充。它必须进入 job payload，并影响角色、讲稿与互动。生成完成后进入现有课程编辑器；编辑器的自动保存继续使用课程 revision，生成任务只提交其启动时绑定的 revision，绝不覆盖之后的人工编辑。

## 5. 执行顺序与大节点校验

实施顺序：`P0 → P1 → P2 → P3 → P4 → P5/P6 → P7 → P8 → P9`。

大节点一（P0–P3）：检查类型、相关单测、真实 PG 的任务/租约契约，并用小型 PPT 验证页面与 roster。  
大节点二（P4–P7）：检查逐页恢复、动作引用、TTS 资产、事件重连，并进行编辑器/播放器联调。  
大节点三（P8）：跑完整回归和生产真实 PPT 冒烟，记录资源峰值、耗时及失败恢复。  
大节点四（P9）：检查令牌权限、跨用户隔离、幂等和两个外部客户端。

门禁保持实用：代码格式、类型、变更范围单测、关键契约和一条真实业务闭环必须通过；与本卡无关的历史测试失败单独记录，不阻塞功能推进。

## 6. 明确不在本轮重复建设

- 不重新设计已确认的课程创建页面。
- 不为 PPT 页面重新生成视觉稿。
- 不承诺旧 `.ppt`、全部动画、宏和超大嵌入视频保真。
- 不先造通用工作流平台；复用现有 generation job/step/worker。
- 不因 Skill 入口隐藏而降低网页端能力，也不为外部 Skill 建缩水版引擎。
