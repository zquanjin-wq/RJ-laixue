## 3. B 批次：可靠生成与正式课程提交

### B1 任务仓储、阶段记录和执行权

依赖：A3。范围：JobRepository、增量 migration、生成阶段 repository。

- [ ] 复用 background_jobs；新增幂等信息、执行代次与阶段记录。
- [ ] channel/inputKind/operation 分开；入队固定 courseId。
- [ ] 原子领取，数据库时间续租，过期恢复，有限退避及最终失败。
- [ ] 进度、产物、状态和提交均验证执行代次、租约及当前状态。
- [ ] 同 key 同请求返回原任务，不同请求 409；终态不被迟到写覆盖。
- [ ] 兼容已有任务消费者；真实 PostgreSQL 测试锁和约束。

验收：两个 worker 竞争只有一个有效执行者，过期旧 worker 所有后续写入被拒。pg-mem 仅辅助，不代替真实并发测试。

### B2 固定阶段与恢复

依赖：B1。范围：classroom-generation、场景/媒体/TTS 领域函数。

- [ ] 拆成路线图指定阶段，保存大纲、ID、内容、动作、音频及指纹。
- [ ] 重启复用完成步骤，仅重做无可靠产物的步骤。
- [ ] 固定非秘密配置版本，密钥执行时获取；缺配置明确失败。
- [ ] 分类错误与重试，限制 SDK/步骤/任务层累计尝试。
- [ ] 记录实际用量及可能重复外部调用；不承诺计费恰好一次。
- [ ] 根据必需/可选步骤输出失败或带警告草稿，不能静默丢页。

验收：中断恢复后已完成页和 ID 保持；同输入步骤可复用；必需能力失败不能报告完整成功。

### B3 正式课程事务提交

依赖：B1、B2。范围：CourseRepository、提交应用服务、资产仓储。

- [ ] 支持共享 PoolClient，任务和课程在同一个事务内提交。
- [ ] 锁任务并重验执行权、租约、取消、用户权限和资源归属。
- [ ] 创建型按固定 ID 写 app.courses；增强型校验 sourceRevision。
- [ ] 绑定已就绪资产，更新 revision 和任务 succeeded；COS/模型在事务外。
- [ ] 重放已提交任务返回同课程/revision。
- [ ] 改稿冲突保留教师内容和候选产物；删课/禁用禁止提交。
- [ ] URL 基于可信应用配置，正式结果可按现有权限读取。
- [ ] 仅得到草稿，发布/学员授权仍由原有业务完成。

验收：结果在教师列表且能重开；事务失败不出现任务成功但课程缺失；重复请求不重复课程；并发编辑不被覆盖。

### B4 Worker、站内 API 与切换

依赖：B1–B3。范围：Compose、runner、generate-classroom POST/GET。

- [ ] POST/GET/取消统一权限，未授权对象不可查询，错误不暴露内部栈。
- [ ] 心跳、优雅停止、超时恢复、取消检查和尽力 Abort。

- [ ] 新任务只写 PG；旧入口停单、排空或明确结束；旧记录按需只读。
- [ ] 保留既有网页分场景生成兼容，明确首批切换的入口。
- [ ] 演练 app/worker 重启、数据库暂不可用与兼容版本回滚。

验收：文本输入到正式课程端到端通过；不再以文件结果表示完成；无同任务双写或双 runner；停新 worker 不影响已有课程学习。

## 8. 故障注入验收矩阵

| 场景 | 预期 | 任务 |
|---|---|---|
| 同 key 并发 | 一任务、一业务提交；异请求 409 | B1/B3 |
| A 丢租约、B 接管、A 恢复 | A 的后续写入与提交拒绝 | B1/B4 |
| 模型返回、保存前崩溃 | 该步可重做、费用可追踪、不重复课程 | B2 |
| 阶段保存后重启 | 复用产物和 ID | B2/B4 |
| 提交成功、响应前退出 | 查询/重放仍返回相同 courseId/revision | B3 |
| COS 成功、DB 失败 | 复用或延迟回收，不误删已绑定对象 | B3/C1 |
| 取消与提交竞争 | 数据库锁顺序产生单一终态 | B3/B4 |
| 教师改稿/删课/禁用 | 不覆盖或越权，冲突/失败明确 | B3/E1 |
| 必需 TTS 失败或 PPT 丢页 | 不报告完整成功 | B2/D1 |
| PPT 超限/外部引用/关闭网页 | 有界失败或重解析，来源保留 | A2/C1/F1 |
| 关闭入口/回滚 | 新任务保留、不转回 JSON runner | B4 |
| 发布后学员学习 | 权限、快照、移动端与报告一致 | C2/D1/F2 |

相关单元、真实 PG 契约、类型检查、DSL 金丝雀及必要 E2E 按变更范围执行。文档修改不宣称业务测试通过。
