# 组织与账号管理重构功能契约

> 状态：待产品确认
> 日期：2026-09-14

## 1. 目标

把当前管理端拆成两条清晰的工作线：

1. **教学工作台**：课程管理、学习任务。
2. **组织与账号**：组织架构、成员账号、账号管理授权。

平台管理员拥有全局账号管理权；老师只有在被管理员授权后，才能管理自己组织范围内的学员账号。

## 2. 已有功能（必须保留）

- 账号角色为 `admin` / `teacher` / `learner`。
- 管理员可创建、重置密码、启用和停用教师与学员。
- 初始密码只在创建或重置后显示一次。
- 新账号和被重置密码的账号在首次登录后必须改密。
- 停用账号不允许继续使用系统。
- 教师和管理员可管理课程与学习任务，现有课程归属和任务权限不因本次重构改变。

## 3. 拟新增功能

### 3.1 组织架构

- 管理员可新建、编辑、停用组织节点。
- 组织支持树形层级，例如：公司 / 事业部 / 大区 / 部门。
- 教师和学员均绑定一个主组织节点。
- 首版不支持一人多组织，避免权限范围不可预测。

### 3.2 账号管理授权

- 管理员可给教师开启或关闭“账号管理”能力。
- 授权时必须指定管理范围：仅本组织，或本组织及所有下级组织。
- 被授权教师只能查看和管理授权范围内的 `learner`。
- 被授权教师可创建学员、编辑学员基本资料、重置密码、启用或停用学员。
- 被授权教师不能创建或管理教师、管理员，不能变更任何人的角色，不能给别人授权。
- 平台管理员不依赖授权记录，始终拥有全局管理权。

### 3.3 账号列表

- 统一展示姓名、邮箱、角色、组织、账号状态、首次改密状态、创建时间。
- 支持姓名/邮箱搜索，按角色、组织、启停状态筛选。
- 管理员可切换“全部 / 管理员 / 教师 / 学员”。
- 被授权教师只看到自己权限范围内的学员，界面上不展示越权数据或越权操作入口。

## 4. 页面信息架构

### 教学工作台

- 我的课程
- 学习任务

### 组织与账号

- 成员账号
- 组织架构（仅平台管理员）
- 账号管理授权（仅平台管理员）

建议将 `/admin` 改为有持久导航的工作台，不再用四张同级卡片表达不同性质的功能。保留旧路由跳转，避免已有书签失效。

## 5. 数据与权限模型

### 新表 `app.organization_units`

- `id`
- `name`
- `parent_id`
- `path`（用于快速判断下级组织）
- `disabled_at`
- `created_at` / `updated_at`

### `app.user_profiles` 新字段

- `organization_unit_id`

### 新表 `app.account_management_grants`

- `user_id`（只允许教师）
- `organization_unit_id`
- `include_descendants`
- `granted_by`
- `created_at` / `revoked_at`

### 新表 `app.account_audit_events`

- `actor_user_id`
- `target_user_id`
- `action`
- `organization_unit_id`
- `metadata`
- `created_at`

## 6. 服务端强制规则

- 所有权限判断在服务端重做，不依赖前端隐藏按钮。
- 创建学员时，服务端校验目标组织是否在操作人授权范围内。
- 编辑、改密、启停时，服务端同时校验目标账号角色和组织归属。
- 不允许任何人停用自己。
- 不允许停用或降级最后一个可用的平台管理员。
- 变更角色、授权、重置密码、启停账号和跨组织调整必须写审计日志。
- 授权被撤销后立即生效，不等待用户重新登录。

## 7. 首版范围

### P0（先做）

- 重构管理端导航，分离教学和账号工作线。
- 组织树与用户单组织归属。
- 统一账号列表、搜索和筛选。
- 管理员授予/撤销教师账号管理权。
- 被授权教师管理组织范围内学员。
- 自我保护、最后管理员保护、审计日志。

### P1（后续）

- CSV/Excel 批量导入和错误回执。
- 批量移动组织、批量启停。
- 邀请邮件与用户自助找回密码。
- 多组织兼职。
- 管理范围模板和更细的操作权限。

## 8. 待确认产品决策

1. 组织层级是否需要固定名称，还是完全自由的树。
2. 被授权教师是否可把学员移到自己管理范围内的其他组织。
3. 学员邮箱是否必填；如果不必填，登录标识需另行定义。
4. 是否需要根据组织限制课程可见性和学习任务分配；本契约默认本期不改动。

## 9. 验收核心场景

1. 未授权教师看不到“组织与账号”入口。
2. 管理员授权某教师管理 A 部门及下级组织。
3. 该教师可创建 A 部门学员，新学员首次登录必须改密。
4. 该教师可重置、停用和恢复 A 部门学员。
5. 该教师无法查看或操作 B 部门学员，即使直接调用 API 也返回 403/404。
6. 该教师无法创建教师、管理员或授权其他人。
7. 管理员无法停用自己，也无法停用最后一个可用管理员。
8. 撤销教师授权后，其下一次请求立即失去账号管理能力。
