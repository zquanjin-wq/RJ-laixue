# P1-B：课程数据地基

> 状态：已完成  
> 日期：2026-09-01

## 本卡范围

P1-B 建立大陆版课程数据模型和最小数据访问层，不切换现有 Supabase 页面，也不接入 COS 上传。

已完成：

- `app.courses`：课程正文、保存状态、课程版本和软删除。
- `app.course_assets`：COS 对象键、文件类型、大小、绑定课程和处理状态。
- `app.course_snapshots`：按课程版本保存发布时正文；同一版本重复请求复用原快照。
- `CourseRepository`：新建、读取、所有者列表、按版本保存、软删除、登记资产和创建快照。
- 真实 PostgreSQL 验证：migration、正常保存、过期版本冲突、资产登记、快照复用和软删除。

## 关键决定

- 保留现有 OpenMAIC 课程 ID 和完整 JSONB 正文，不拆解页面内部结构。
- 课程保存使用递增版本号，避免两个编辑页面静默覆盖。
- 数据库只保存 COS `object_key`，不保存临时访问地址。
- P1-B 不实现 COS 上传、页面改造和课程授权；这些分别由 COS 接入和后续服务切片完成。
